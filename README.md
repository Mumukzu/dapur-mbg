Dapur MBG — a real-time 3D cooking game. Chef Sari runs a bright MBG free-nutritious-meal kitchen: take orders, grab ingredients from the fridge and pantry, chop and cook them, and serve before patience runs out. 10 dishes from 16 ingredients, combo up to x2.0, 150-second shifts.

## Run it

```sh
node serve.ts
```
